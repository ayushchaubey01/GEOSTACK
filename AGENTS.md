# Agent instructions for this repo
Priority order when instructions conflict (highest first):
1. PRODUCT.md: honesty rules. Never imply official ULPINs, real floor plans, ownership, live data or RERA data. Estimated values are labelled "Estimated"; mock units are labelled "Synthetic demo data".
2. DESIGN.md: the project's visual language (light theme, indigo accent, Inter + JetBrains Mono, Whimsical/Linear-style shell). It is a fixed decision, not a suggestion.
3. The current task prompt.
4. Installed skills. Skills advise; they never override 1-3. In particular, anti-generic design skills (including Taste and frontend-design) must not change the palette, fonts or layout defined in DESIGN.md; use them to improve hierarchy, spacing, polish and to remove clutter.
Skill roles: impeccable = critique/polish/detector; web-design-guidelines = final audit; vercel-react-best-practices + vercel-composition-patterns = refactor quality; Playwright/axe/Lighthouse = verification.
Never add a dependency just because a skill mentions it. Free tools only.
